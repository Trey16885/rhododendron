# Rhododendron
[Chat Today](https://trey16885.github.io/rhododendron)
Rhododendron is an AI that tries hard.
It wants to help; it can do a lot.
You can make it have a custom personality or ask about preset personalities.
Gems add their instructions as a conversation turn rather than a system prompt,
so the model keeps the SYSTEM instructions from its Modelfile.
Galla uses Ollama
**Markdown is supported in the chat**
**Galla can make images using SVG**

## Galla CLI

Projects and publishing live in a small CLI, since a browser tab has no files:

```sh
curl -fsSL https://raw.githubusercontent.com/Trey16885/rhododendron/main/CLI/install.sh | bash
```

Then `galla new my-site`, `galla open my-site`, `galla publish my-site`.
See [CLI/README.md](CLI/README.md).
