Ollama Connection Failed

Rhododendron runs locally on your machine, but we couldn't connect to Ollama. Make sure it's installed and running with CORS allowed.

Termux (Android):

pkg install -y ollama && OLLAMA_ORIGINS="*" ollama serve

Windows:

irm https://ollama.com/install.ps1 | iex

# Then run:
OLLAMA_ORIGINS="*" ollama serve

MacOS:

curl -fsSL https://ollama.com/install.sh | sh

# Then run:
OLLAMA_ORIGINS="*" ollama serve

Linux:

curl -fsSL https://ollama.com/install.sh | sh && OLLAMA_ORIGINS="*" ollama serve
